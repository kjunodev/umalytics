# UmaLytics Desktop 0.1.1 beta

- Badges: every badge now shows on lobby cards and in player details (Top 10/25, High scoring, Established, MVP Menace, One-trick, Deep pool, Podium regular, Underrated, Newcomer), in the same style as the extension.
- Badge and team tooltips now appear above the card instead of behind the stats.
- Deep pool has a clearer icon.
- Players: Season / All-time toggle on the Players page and in player details opened from it.
- Stamina: the "Inputs changed since this run" notice no longer appears right after a check when nothing changed.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
