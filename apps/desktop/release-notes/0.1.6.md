# UmaLytics Desktop 0.1.6 beta

- Updates no longer install on their own after a room ends. When an update is ready, it waits for you to click Update and restart (or Restart now during a live room).
- Stamina: Copy diagnostics for an unrecognised course now works even when the draft has no room code.
- If the app's race data is missing, the Stamina page shows a clear error with Copy details instead of failing silently. Other pages keep working.
- Player details: Close is now the first keyboard stop, so Tab and Shift+Tab cycle predictably.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
