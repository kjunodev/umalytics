# UmaLytics Desktop 0.1.3 beta

- Stamina: stat boxes can be cleared while typing. Leaving a box empty restores the last valid number.
- Presets: ballpark buttons now just say Front, Pace, Late, End and Runaway.
- Stamina: the toolbar gear is gone; use the Race settings tab in the build panel.
- Badges: tooltips now show the player's own numbers, such as MVP rate and points per game.
- Badges: Underrated now applies only to Season stats, because rank is a current-season value.
- Hovering a player's name shows their Discord username when it differs from the name shown.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
