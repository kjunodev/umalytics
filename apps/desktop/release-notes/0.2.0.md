# UmaLytics Desktop 0.2.0 beta

- Stamina: redesigned screen with Requirement and Assessment modes, a compact race bar and a build panel with Build, Race and Presets tabs. Presets can now include Stamina (600 by default).
- Season 3: Draft and History show the match's goddess blessing, including Byerley Turk's tiebreaker candidates and bans, and each Uma's running style. Quickplay matches are labelled and show their races in the order they are played.
- Screenshot import (experimental, off by default): turn it on in Settings > Experimental to read your stats and skills from game screenshots or live capture, then plan purchases in the Skill shop with SP left and each skill's HP recovery. Check every scan before applying it.
- Support: a Ko-fi link above Settings.
- Copy diagnostics now lists live-feed fields the app does not recognise yet.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
