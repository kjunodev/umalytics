# UmaLytics Desktop 0.1.2 beta

- Stamina: heal skills are now credited by how often they actually fired in the simulation at your stamina. Conditional heals that cannot trigger in a race (for example After-School Stroll on a course with no downhill, or a skill for a different running style) now show "Never fires in this race" and add nothing.
- Heals that fire only in some simulated races show their firing rate, and count at that rate.
- Pass/short results were never affected: they always came from the simulation, which applies skill conditions. Only the heal list and the effective stamina numbers change.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
