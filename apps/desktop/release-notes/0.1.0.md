# UmaLytics Desktop 0.1.0 beta

- Windows installer with bundled race engine data, skill names and skill icons.
- Background update downloads with an in-app Update and restart banner.
- Updates wait for the current live room to end; Restart now remains available.
- Settings includes update controls and third-party credits.

Beta installers are unsigned. Windows SmartScreen may require More info → Run anyway when manually launching an installer. In-app updates are verified with the Tauri updater signing key.
